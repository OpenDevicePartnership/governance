## Agenda Items

### Item 1: Discuss RFC for the documentation philosophy

- **Submitter:** Karan Dhillon (GitHub: @dhillonk)
- **Decision required:** No
- **Summary:** The RFC proposes an org-wide documentation philosophy that top level project provide a project specific
  mdBook for project documentation. And that project specific documentation should not be hosted in the documentation
  repo.
- **Supporting links:**
  - [RFC PR](https://github.com/OpenDevicePartnership/governance/pull/44)

### Item 2: Discuss RFC for private repo access control

- **Submitter:** Michael Kubacki (GitHub: @makubacki)
- **Decision required:** No
- **Summary:** Updates the RFC to more generally cover private repository policy in the OpenDevicePartnership GitHub
  organization. Adds a requirement that private repositories are only for staging content to go public and should not
  contain any confidential content or material with no public plan. Simplifies requirements and overall policy
  accordingly while still retaining GitHub teams to manage and audit private repository access on a per-repository
  basis.

- **Supporting links:**
  - [RFC PR](https://github.com/OpenDevicePartnership/governance/pull/48)

### Item 3: Discuss RFC for repository naming policy

- **Submitter:** Ron Gurr (GitHub: @rogurr)
- **Decision required:** No
- **Summary:** Define the naming policy for repositories in the Open Device Partnership (ODP) GitHub organization to 
  communicate each repository's scope and purpose. And for repositories temporarily hosted by ODP, communicates whether
  the repository is a fork or is intended for handoff.

- **Supporting links:**
  - [RFC PR](https://github.com/OpenDevicePartnership/governance/pull/50)

### Discussion Summary

For each agenda item, summarize the discussion and the decision made.

#### Minutes for Item 1

- **Discussion:** Karan led a discussion on the new RFC proposing a standardized documentation philosophy for the ODP
  organization, with input from Phil, Michael, and Ron, focusing on moving project-specific documentation out of the
  central documentation repository and into project-level repositories, and outlining migration and flexibility for
  maintainers. Clarified that no timeline is being specified to move project documentation out of the documentation
  repository.
- **Decision:** No decision was made.

#### Minutes for Item 2

- **Discussion:** Michael presented an update to the RFC on private repository access, clarifying that ODP private
  repositories should only be used for staging content intended to go public and must not contain confidential
  material, with feedback and legal considerations discussed by Phil, Jerry, and others.
- **Decision:** No decision was made.

#### Minutes for Item 3

- **Discussion:**  Ron introduced an RFC for repository naming conventions in ODP, aiming to improve clarity and
  consistency in repository names, with feedback from Jerry, Felipe, Michael, and others on the proposed tagging
  scheme and its implications for forks, handoffs, and project association.
- **Decision:** No decision was made.
